# Rallye du Pyla

Prototype du nouveau site du Rallye du Pyla : événements automobiles lifestyle sur le Bassin d'Arcachon (La Noctambule, Les Chapeaux de Roues, GT Tour, Rallye Pyla Coffee, Apéro Capot).

## Voir le prototype

Site statique, aucune dépendance. Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```
python -m http.server 8080
```

## Direction artistique

- Photos des éditions passées au centre, design épuré et premium
- Fond sable clair `#FAF8F5`, encre `#14181F`, accent unique : le rouge plaque du logo `#D63A27`
- Typographies auto-hébergées (RGPD) : Fraunces pour les titres, Hanken Grotesk pour le corps
- Aucun CDN externe, aucune bibliothèque : HTML, CSS et JS purs

## Contenu

Les textes, dates, tarifs et chiffres proviennent du site actuel (rallyedupyla.fr) et de la presse locale. Prototype non contractuel : à faire valider par l'organisation avant toute mise en ligne.

Photos des éditions passées : Lucas Bouveyron, Vincent Bourgain, Pierre-Alexis Gaudou, Clément Roy.
